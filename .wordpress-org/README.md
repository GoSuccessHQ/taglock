# WordPress.org Plugin Assets

This directory contains assets for the WordPress.org Plugin Directory.

## Required Assets

### Banners
- `banner-772x250.png` or `banner-772x250.jpg` - High DPI banner (required)
- `banner-1544x500.png` or `banner-1544x500.jpg` - Low DPI banner (optional)

### Icons
- `icon-128x128.png` - Small icon (required)
- `icon-256x256.png` - Large icon (required)

### Screenshots
- `screenshot-1.png` - First screenshot (matches "== Screenshots ==" section in readme.txt)
- `screenshot-2.png` - Second screenshot
- etc.

## Notes

- These assets will be automatically deployed to WordPress.org when changed
- Changes to this directory or readme.txt trigger the asset update workflow
- Use PNG format for best quality
- Ensure images are optimized for web

## Current Assets

Add your plugin assets to this directory before releasing to WordPress.org.
